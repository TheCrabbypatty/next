# Next

> **Too much to do, too little time. Next cuts through the noise, weighs what matters, and tells students exactly what to do next.**

Next is a hackathon prototype that uses a large language model to recommend the best next task for a student to tackle.

Given a task name and an estimated completion time, Next analyzes the available tasks and recommends which one should be worked on next.

## How It Works

1. Enter the tasks you need to complete.
2. Provide an estimated amount of time for each task.
3. Next sends the task information to an LLM.
4. The LLM determines which task is the best one to tackle next.
5. The recommendation is displayed through the web interface.

The goal is not to replace a calendar or task manager, but to answer a simpler question:

> **"What should I do next?"**

## Project Status

This project was created as a **hackathon prototype**. The focus was on building and demonstrating the core idea rather than implementing a large number of features.

## AI Usage

The project uses an LLM through OpenRouter to analyze the provided tasks and generate the next-task recommendation.

GitHub Copilot was also used during development for debugging and development assistance.

## Future Possibilities

Potential future improvements could include:

* Deadlines and due dates
* Calendar integration
* Task priorities
* Available-time constraints
* More detailed reasoning behind recommendations
* Personalized recommendations based on previous decisions
* Persistent task storage

These features are intentionally outside the scope of the current prototype.

## Running Locally

Clone the repository and install the required dependencies.

```bash
git clone <repository-url>
cd <repository-directory>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Then start the Django development server:

```bash
python manage.py runserver
```

Open the local development address shown by Django in your browser.

## Disclaimer

Next is an experimental hackathon project. Its recommendations are generated by an LLM and should be treated as suggestions rather than authoritative decisions.
